# Bounded sector native milestone

The bounded core/native sector implementation is qualified on the exact frozen
snapshot9 source. Version 0.5.2 remains the latest usable release. This milestone
does not enable a service or an add-on arc workflow.

## Useful result

The frozen snapshot9 kernel constructs and extrudes the supported circular-sector
profiles across all 70 predeclared positive cases. Both directions, quarter and
major sectors, noncardinal and nonquadrantal endpoints, positive endpoint gaps,
local center offsets, scale endpoints and separately authored radius-5/radius-7
examples passed the complete native profile, generated-face trace and fixed
area/volume checks. Every case produced one accepted profile and one accepted
solid. These geometry examples are not yet a service-driven radius-edit workflow.

The source is one circular arc plus two radial lines with shared endpoint IDs.
The reviewed support domain requires exact authored-ray dot <= 0, radii and
extrusion heights from 1 to 1000 mm, and an exact necessary endpoint discrepancy
limit of 1e-9 mm. Passing the discrepancy test alone is insufficient: complete
source incidence, root/membership, native representation and trace checks remain
required. Exact signed-permutation sketch frames at zero world origin are the
native placement support limit; tested local center offsets are supported.
Coincidence-only joins and arbitrary multi-arc loops remain outside this slice.

## Authored and native coordinates

Canonical authored coordinates and endpoint IDs are preserved. The native
construction explicitly maps each authored arc endpoint to one prescribed circle
point, proved inside the fixed existing incidence cells. One native vertex per
endpoint ID is shared consistently across the cap, radial edges, cylinder and
extrusion history. This is a bounded native projection, with retained mapping
evidence. It is not a claim that native coordinates equal the authored doubles.

The previous positive-gap representation mismatch and all failed attempts remain
recorded. The now-passing run uses the reviewed common native endpoint policy.
No per-case retry, hidden repair, mass allowance widening or adaptive domain
relaxation was used.

## Numerical and native evidence

Pure exact arithmetic certifies the documented bounds and finite-membership
claims. Actual OCCT area/volume measurements are empirically qualified against
those fixed bounds; these tests do not turn native floating-point integration
into a mathematical certification of every possible accepted input.

The optional OCCT continuity record is advisory metadata only. Eight actual
cases carried C2 records bound to the two adjacent radial planes, including
near-antipodal cases. The label never establishes geometric continuity or waives
any trace, orientation, placement, validity or mass check.

The single serialized child completed all 70 in original order, exit 0, with
matching source/runtime identities before and after. Observed maximum work was
144,634 of 200,000 total checked operations; source completion remained below
100,000. Maximum complete evidence was 417,185 compact bytes, 7,237 nodes,
depth 11 and 56 events. All fixed limits remain unchanged.

## Negative gates and next boundary

All 26 original invalid-input rows and 35 original adversary rows have completed
their predeclared controls. The combined distinct kernel/native-path subcases are
14 genuine native mutations, 22 injected observations on real native paths and
28 kernel-entry rejections before forbidden construction. Two further input rows
reject at the parser before kernel entry. Twenty-one detached pure controls are
reported separately. There were no unexpected acceptances or pending native
subcases. Every child was collected before the next process started.

The oversized solid-evidence control rejects at the mass-event candidate size
guard, before event append and solid registration. This covers the original
aggregate evidence-ceiling obligation; the later final-registration suffix is
covered by detached controls only. Failed extrusion controls retain accepted
profile evidence and registry state exactly. The original proxy-overload fixture
failure is preserved separately from the corrected ten-case passing run.

Independent review accepted the complete prescribed native evidence. The full
Git-free source regression passed 9,687 tests and 19,597 subtests in 346.34 seconds;
Ruff and formatting passed for 405 Python files. One non-failing pytest
deprecation remains: the end-cap test passes an itertools.product iterator to
parametrize. All three child processes were collected with exit 0. Fourteen
generated bytecode cache files were preserved separately; both tested/reference
source trees returned to their exact 995-file sets and hashes.
