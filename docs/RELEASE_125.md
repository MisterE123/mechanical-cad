# 1.25.0 Linux feature checkpoint

This separate checkpoint follows frozen Linux 1.24.0. All earlier source tags
and artifacts remain unchanged.

## Changes

- Sketch Corner Fillet trims two supported straight lines sharing an authored
  corner and adds a tangent minor arc plus explicit radius and support relations.
  Apply is one checked command; Cancel preserves accepted authoring. The original
  corner remains a dimensionable witness. See [scope](SKETCH_CORNER_FILLET.md).
- New arcs carry strict, persistent version-1 `fillet_intent`. Native solve and
  independent add-on evidence checks reject oversized edits that would flip the
  supporting segment or directed arc branch. Failed trials preserve the accepted
  sketch and canonical Part. Legacy sketches are not rewritten; older strict
  readers reject new metadata and cannot Resume the new journal opcode.
- Gear-pair Edit and gear source-Part actions appear before Instances instead of
  behind expanded Reusable Parts. Gear-coupled joints show driver guidance;
  ordinary connector controls retain their behavior. See [exercise](GUI_GEAR_PAIR_EXAMPLE.md).
