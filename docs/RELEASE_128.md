## Implemented scope

- Operation-family feature-history glyphs retain independent status, output and
  editing indicators; narrow-panel readability was checked. Build freshness and
  explicit geometry checking now have separate, truthful labels.
- Simple exact named extrusion-depth and primitive-circle radius references offer
  explicit **This feature only** or **Shared parameter** editing with affected
  uses shown. Final Cut/Union tool depths offer **Tool formula only** versus the
  named parameter; independent shared-tool consent is still required. Formula
  expressions retain the existing editor. Circle fields are radius, not diameter;
  the constrained-sketch diameter tool is unchanged.
- Missing shared-tool permission is a typed preflight refusal, not a geometry
  failure. Its draft returns once with consent false and exact context guards.
  Cancel does not reopen; stale/closed/newer-editor contexts revoke the return.
- Shared radius updates preserve simultaneous support-body/face edits by applying
  the face to the final detached candidate, not an obsolete reference.

No canonical model schema, solver authority, automatic cleanup, public publishing,
or manufacturing qualification is introduced. Local recovery remains OFF by
default. Historical unresolved allocator and distribution-material facts remain.
