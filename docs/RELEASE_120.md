# 1.20.0 Linux development checkpoint

This checkpoint follows the immutable Linux 1.19 source and installer. It adds:

- A guarded hover preview before reusing a unique existing sketch point.
- Quiet current-success geometry confirmations, with detailed reports retained.
- Named fresh-Part starters and plain-language pending rebuild status.
- A guarded pencil action beside Assembly instances to open their source Part.
- An explicitly unlinked sketch plane sampled from a current exact planar face.
- A signed, one-time offset along an existing fixed sketch plane's normal.

Copied planes remain ordinary literal planes, not imported-face identity or
associations. They do not follow the source. Offset does not detach linked
sketches or add parameter associations. Canonical graph authority, failure
visibility, guarded atomic publication and the isolated native sidecar remain
unchanged. See [copied plane and offset scope](COPIED_FACE_PLANE.md).

## Evidence boundaries

The companion release receipt identifies the exact frozen source, archive hashes,
and checks actually completed. This scope document is not a passing receipt.
Focused source tests and bounded native Blender 5.2.2 checks cover individual
changes. Retained source-loaded GUI observations cover the inspected fixtures
only. They are not exact installed-package GUI qualification; later selection
or copy changes need their own checks and do not inherit earlier GUI evidence.

The exact installer is checked separately using an isolated profile: ZIP install
and enable, version and committed-source identity, installed file bytes, bundled
runtime hashes and modes, then representative edit, geometry Check, save and
independent-process reopen. Native OCP/SolveSpace must remain outside Blender.
No exhaustive GUI Apply/Cancel/Undo/Redo, full historical-suite, complex enclosure,
Windows 1.20 or manufacturing certification is claimed. The known historical
packaging byte-pin baseline failure is retained and is not weakened to pass.

## Immutable runtime and materials

Frozen 1.19 and earlier deliverables remain unchanged. The 1.20 builder reuses
exactly 1,030 external runtime files from the verified Linux 1.18 payload, checking
their hashes and retaining their modes. Only project source and trusted bootstrap
are substituted under the existing packaging contract. The original runtime-lock
bytes, dependency materials and historical source declarations are retained;
current source, license and provenance are appended with explicit identity.
The development virtual environment is not distributed.

The native pin remains cadquery-ocp-novtk 8.0.1.1.0. Existing unresolved dependency
materials/source issues remain unresolved. Packaging is not legal clearance,
proof of dependency source correspondence or proof of a recipient rebuild.
