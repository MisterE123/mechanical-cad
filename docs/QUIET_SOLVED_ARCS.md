# Contextual arc captions

Current solved sketch arcs show their geometry, point markers and authored
editable dimensions without routine Center/Start/End captions or generic
sweep/radius diagnostics. Select an arc or any of its defining points to reveal
that arc's roles and details. Shared selected points can reveal multiple arcs.
This uses the existing detached selection state, not extra hover queries.

Authored or retained unverified geometry, active arc proposals, and any meaningful
raw-end radius discrepancy beyond the shared arc policy keep explanatory captions.
Harmless residuals within that existing absolute/relative policy do not reveal
routine text; original discrepancy strokes are unchanged. Selected solved fillets
reveal role captions but retain their compact editable radius annotation instead
of redundant generic diagnostics. Unverified/discrepant fillets retain guidance.
No geometry, constraint, identity, native evidence or dimension editing is changed.
Solved currency is not a new fully-defined/zero-DoF claim. Existing status and
incomplete-display reporting remain visible. Captions are not hit targets;
only the existing visible dimension labels contribute dimension hitboxes.

## Verification boundary

Focused pure frame/geometry tests and graphics-stub draw tests cover restored
selection details, quiet generic/fillet arcs, unchanged point/stroke identity,
authored dimensions, hitboxes, discrepancy guidance, proposal guidance,
projection failures and currency rejection. Synthetic display fixtures do not
establish native solving. Targeted Ruff passes. Native/Blender GUI, installed
archive and full-suite qualification are not established by this change.

## Selected-caption spacing

Selected solved arc captions use measured text bounds and a fixed, bounded search
for nearby vertical slots. Role text avoids existing point markers, dimension
boxes and prior role text; generic diagnostics avoid those captions too. Displaced
roles have short point-to-caption leaders. Marker positions, dimension placement
and hitboxes do not move. Typography stays fixed. Authored/unverified and proposal
presentation is unchanged. If a crowded viewport cannot fit the captions, the
original visible/clipped placement remains rather than suppressing guidance.

Focused graphics-stub tests cover two-pixel arcs, three UI scales, viewport-edge
clamping, marker/dimension/caption separation and a fixed 32-attempt search cap.
Actual GUI qualification of this spacing follow-up is pending separately.

Current solved generic arcs within the existing residual policy show a compact
radius alongside their signed sweep/direction context, not raw residual/debug
wording. Construction arcs explicitly retain their construction-reference label.
Unverified/provisional and materially discrepant diagnostics keep their full
existing guidance. This changes displayed wording only, not tolerance, markers,
strokes, source geometry or authored dimensions.
