# Mechanical CAD integration

This offline source/resource pack is copied from the reviewed project icon pack.
The host wires only supported actions; manifest availability describes the asset
catalog, including unwired future actions. Use PNG previews in Blender; do not
pass these SVGs to Blender's native toolbar icon loader.

The host copy formats the Python rebuild/validation scripts and adds an explicit
strict zip-length check. SVG/PNG artwork and upstream source hashes are unchanged.
The checksums below describe this integrated copy. Rebuilding requires Pillow,
Inkscape, and the documented font; runtime loading requires neither.
